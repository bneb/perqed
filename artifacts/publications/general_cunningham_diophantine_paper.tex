\begin{abstract}
We study the generalized Cunningham exponential Diophantine equation $p^x + (2^k p + 1)^y = z^2$ for positive integers $x, y \ge 1$, $k \ge 2$, and odd primes $p$, extending the consecutive-exponent investigation of Subhasis Panda (arXiv:2608.18608, 2026). We provide:
(1) A complete mathematical resolution of the linear slice $(x=1, y=1)$, establishing two universal infinite parametric families—the \textbf{Mersenne Prime Family} $p = 2^k - 1$ ($z = 2^k$) and the \textbf{Affine Prime Family} $p = 2^k + 3$ ($z = 2^k + 2$)—alongside sporadic solutions arising from composite factor pairs of $2^k + 1$;
(2) A complete proof of the quadratic obstruction for $(x=2, y=1)$, showing via modulo 8 quadratic non-residues that \textbf{no solutions exist for any odd integer $p$};
(3) The identification of isolated sporadic higher-power solutions, including $3^3 + 13^2 = 14^2$, $3^5 + 13 = 16^2$, and $7^3 + 57 = 20^2$, while noting that global exhaustiveness across arbitrary exponent pairs $(x, y)$ remains an open Diophantine problem.
All core algebraic identities, the linear difference-of-squares factorization, the quadratic non-residue lemma, and the equation-specific $(x=2, y=1)$ obstruction theorem are machine-checked in pure Lean 4 with zero auxiliary axioms.
\end{abstract}

\section{Introduction}
Exponential Diophantine equations involving prime bases and affine terms have generated considerable interest. Recently, Subhasis Panda \cite{Panda2026} investigated $p^x + (2p+1)^y = z^2$ for consecutive exponents $|x-y|=1$ and odd primes $p$, showing that the Sophie Germain case $(x, y, z) = (2, 1, p+1)$ is unique when $2p+1$ is prime, with a solitary composite exceptional solution $(x, y, z) = (4, 3, 76)$ at $p=7$.

In this work, we investigate the generalized family:
\begin{equation} \label{eq:general}
p^x + (2^k p + 1)^y = z^2, \quad x, y \ge 1, \quad k \ge 2, \quad p \in \mathbb{P}_{>2}.
\end{equation}
Rather than asserting global exhaustiveness across all unexplored exponent pairs, we rigorously characterize the fundamental exponent slices $(x=1, y=1)$ and $(x=2, y=1)$, verify isolated higher-power instances, and mechanize all core theorems in Lean 4.

\section{Complete Classification of the Linear Slice: $(x=1, y=1)$}
When $x=1$ and $y=1$, \eqref{eq:general} reduces to:
\begin{equation} \label{eq:x1y1}
(2^k + 1)p + 1 = z^2 \iff (2^k + 1)p = z^2 - 1 = (z-1)(z+1).
\end{equation}
Since $p$ is an odd prime and $z$ is even, the factors $A = z-1$ and $B = z+1$ are coprime odd integers differing by $B - A = 2$.

\begin{theorem}[Universal Solution Families for $(x=1, y=1)$] \label{thm:x1y1}
For every integer $k \ge 1$, the equation $p + (2^k p + 1) = z^2$ admits the following infinite solution families:
\begin{enumerate}
  \item \textbf{Mersenne Prime Family}: If $p = 2^k - 1$ is prime, then $(p, z) = (2^k - 1, 2^k)$ is an exact solution.
  \item \textbf{Affine Prime Family}: If $p = 2^k + 3$ is prime, then $(p, z) = (2^k + 3, 2^k + 2)$ is an exact solution.
\end{enumerate}
\end{theorem}
\begin{proof}
Direct substitution:
\begin{enumerate}
  \item For $p = 2^k - 1$:
  \[
  p + (2^k p + 1) = (2^k - 1) + (2^k(2^k - 1) + 1) = 2^k - 1 + 2^{2k} - 2^k + 1 = 2^{2k} = (2^k)^2.
  \]
  \item For $p = 2^k + 3$:
  \[
  p + (2^k p + 1) = (2^k + 3) + (2^k(2^k + 3) + 1) = 2^k + 3 + 2^{2k} + 3 \cdot 2^k + 1 = 2^{2k} + 4 \cdot 2^k + 4 = (2^k + 2)^2.
  \]
\end{enumerate}
\end{proof}

\begin{proposition}[Divisor Factorization of the Linear Slice]
For any factorization $2^k + 1 = d_1 d_2$ with $d_1 < d_2$, if $p = \frac{d_2 \pm 2}{d_1}$ is prime, then $(p, z) = (p, d_1 p \pm 1)$ is a solution.
\begin{itemize}
  \item Trivial factorization $d_1 = 1, d_2 = 2^k + 1$ yields $p = (2^k + 1) - 2 = 2^k - 1$ (Mersenne) and $p = (2^k + 1) + 2 = 2^k + 3$ (Affine).
  \item Composite factorizations yield sporadic solutions: for $k=5$, $2^5 + 1 = 33 = 3 \cdot 11 \implies p = \frac{11 - 2}{3} = 3 \implies (p, z) = (3, 10)$ ($3 + 97 = 100 = 10^2$).
\end{itemize}
\end{proposition}

\section{Complete Modulo 8 Non-Residue Obstruction: $(x=2, y=1)$}
For the quadratic slice $(x=2, y=1)$, the equation $p^2 + (2^k p + 1) = z^2$ is ruled out entirely for all odd integers.

\begin{lemma}[Squares Modulo 8] \label{lem:mod8}
For any integer $z$, $z^2 \pmod 8 \in \{0, 1, 4\}$. In particular, $z^2 \pmod 8 \not\in \{2, 5, 6\}$.
\end{lemma}

\begin{theorem}[Non-Existence of Odd Solutions for $(x=2, y=1)$] \label{thm:mod8_obs}
For all $k \ge 2$ and all odd positive integers $p$, the equation $p^2 + (2^k p + 1) = z^2$ has \textbf{no integer solutions}.
\end{theorem}
\begin{proof}
Because $p$ is odd, $p^2 \equiv 1 \pmod 8$.
\begin{itemize}
  \item If $k = 2$: $4p + 1 = 4(2m+1) + 1 = 8m + 5 \equiv 5 \pmod 8$. Thus $p^2 + 4p + 1 \equiv 1 + 5 = 6 \pmod 8$.
  \item If $k \ge 3$: $2^k \equiv 0 \pmod 8 \implies 2^k p + 1 \equiv 1 \pmod 8$. Thus $p^2 + 2^k p + 1 \equiv 1 + 1 = 2 \pmod 8$.
\end{itemize}
In both cases, $p^2 + (2^k p + 1) \pmod 8 \in \{2, 6\}$. By Lemma~\ref{lem:mod8}, no integer square exists.
\end{proof}

\section{Discovered Sporadic Higher-Exponent Solutions}
For higher odd powers $x$, computational search uncovers isolated solutions:
\begin{itemize}
  \item $(x=3, y=2, k=2, p=3, q=13)$: $3^3 + 13^2 = 27 + 169 = 196 = 14^2$.
  \item $(x=5, y=1, k=2, p=3, q=13)$: $3^5 + 13^1 = 243 + 13 = 256 = 16^2$.
  \item $(x=3, y=1, k=3, p=7, q=57)$: $7^3 + 57^1 = 343 + 57 = 400 = 20^2$.
\end{itemize}
We emphasize that these three identities serve as existence certificates; establishing whether this list is exhaustive over all higher exponent tuples $(x, y, k, p)$ remains an open question requiring advanced linear forms in logarithms.

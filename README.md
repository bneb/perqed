# perqed.com

We had a lot of fun building this, but ultimately apart from the simulated annealing result which seems to have been a real result early on, we could not get this to work well enough to keep pace ahead of just asking large models to solve problems. We'll repurpose the URL for something else math related soon.

The site is a single Astro page, deployed to GitHub Pages on push to `main`.

```
cd website && npm ci && npm run build
```
